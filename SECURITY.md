# Security Policy

## Reporting a vulnerability

Please report vulnerabilities privately through
[GitHub's security advisory form](https://github.com/abendrothj/simgit/security/advisories/new).
Do not open a public issue for an undisclosed vulnerability.

Include the affected version or commit, reproduction steps, impact, and any
suggested mitigation. Reports will be acknowledged as soon as practical.

## Supported versions

Only the latest `main` revision and the latest published release receive
security fixes. The current release is listed on the
[releases page](https://github.com/abendrothj/simgit/releases).
